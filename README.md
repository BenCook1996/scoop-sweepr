# SWEEPR Cleaner — Official Scoop Bucket

Official [Scoop](https://scoop.sh/) manifest repository for **SWEEPR Cleaner** (`v0.1.0`), a fast native Rust Windows 10 & Windows 11 PC and SSD storage cleaner with a 7-day undo safety net.

## Install via Scoop

```powershell
scoop bucket add sweepr https://github.com/BenCook1996/scoop-sweepr
scoop install sweepr/sweepr-cleaner
```

*(Also available via Winget PR [`microsoft/winget-pkgs#480164`](https://github.com/microsoft/winget-pkgs/pull/480164) and direct download at [sweeprcleaner.com/download](https://sweeprcleaner.com/download).)*

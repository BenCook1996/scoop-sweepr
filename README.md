# SWEEPR — Official Scoop Bucket

Official [Scoop](https://scoop.sh/) manifest repository for **SWEEPR** Windows utilities, including **SWEEPR Cleaner** (`v0.1.0`) and **SWEEPR VPN** (`v2.5.0`).

## Install via Scoop

```powershell
scoop bucket add sweepr https://github.com/BenCook1996/scoop-sweepr

# Install SWEEPR VPN (10Gbps WireGuard VPN + Free 30s Home Wi-Fi Scanner)
scoop install sweepr/sweepr-vpn

# Install SWEEPR Cleaner (Native Rust PC & SSD Storage Cleaner)
scoop install sweepr/sweepr-cleaner
```

*(Also available via Winget PRs [`microsoft/winget-pkgs#480736`](https://github.com/microsoft/winget-pkgs/pull/480736) and [`microsoft/winget-pkgs#480164`](https://github.com/microsoft/winget-pkgs/pull/480164), and direct download at [sweeprvpn.com/download](https://sweeprvpn.com/download) / [sweeprcleaner.com/download](https://sweeprcleaner.com/download).)*
